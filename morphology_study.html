🧩 ① Morpheme — free / bound, root / stem / base / affix 최소 의미 단위 ▼
Core Definition
A morpheme is the minimal unit of meaning or grammatical function. A free morpheme can stand alone as a word; a bound morpheme must attach to another form. All affixes in English — prefixes and suffixes — are bound morphemes.

morpheme(형태소)은 의미·문법 기능을 가지는 최소 단위다. 독립된 단어로 쓰일 수 있으면 free, 반드시 다른 형태에 붙어야 하면 bound다.

root는 더 쪼갤 수 없는 핵심 형태다. Fromkin의 용법에서 stem은 root에 affix가 결합한 형태이며, 여기에 affix가 더 붙어 복잡한 stem이 될 수 있다. base는 affix가 붙는 대상인 root 또는 stem을 포괄한다. players에서 play는 root, player는 play + -er로 만든 stem이며 -s가 붙을 때의 base다. stem의 범위는 교재마다 다를 수 있으므로 base와 무조건 동의어로 외우지 않는다.

affix는 bound morpheme으로, base 앞에 붙으면 prefix, 뒤에 붙으면 suffix다.

free morpheme
혼자 단어로 성립book, travel, cat, play
bound morpheme
단독 사용 불가 (affix·bound root 포함)re-, -ist, -ed, -s, -ness
unkindness = un-(prefix, bound) + kind(root, free) + -ness(suffix, bound) → 3 morphemes players = play(free root) + -er(bound, agentive) + -s(bound, plural) cats = cat(free) + -s(bound) book = single free morpheme (no internal structure) root는 free일 수도 bound일 수도 있으나, 영어에서 affix는 예외 없이 모두 bound다.
📋 개념 확인

형태소 분류 — free vs bound, lexical vs functional 구분이 형태론의 기본 분류다.

morpheme과 철자·syllable 구분

repainted를 re- + paint + -ed로 분석하면 반복 의미, paint의 의미, past 기능이 각각 확인된다. 반면 carpet의 철자 car를 잘라 독립적인 ‘자동차’ 의미를 부여할 수는 없다. 같은 형태가 반복될 때 의미나 grammatical function도 일정하게 대응하는지 확인해야 한다.

repaint는 -ed가 붙을 때 base이고 paint는 root다. base는 결합 단계마다 달라질 수 있다. bound라는 기준은 ‘단독 단어 가능 여부’이므로 bound morpheme에는 affix뿐 아니라 bound root도 있다.

morpheme 수와 syllable 수를 혼동하지 않는다. giraffe는 여러 syllable을 가지지만 이 분석에서는 하나의 morpheme이고, painted는 paint와 past morpheme을 포함한다.

🗂️ ② Lexical vs Functional morphemes open vs closed class ▼
Core Definition
Lexical morphemes are content-bearing free morphemes (ordinary nouns, verbs, adjectives, adverbs); new ones are added easily → open class. Functional morphemes are function words (conjunctions, prepositions, articles, pronouns); new ones are almost never added → closed class.

free morpheme은 다시 lexical과 functional로 나뉜다. lexical은 사물·행동·속성 등의 내용을 나타내는 noun·verb·adjective 등으로, 새로 잘 만들어지므로 open class다.

functional은 conjunction·preposition·article·pronoun 같은 기능어로, 거의 추가되지 않으므로 closed class다.

보조: derivational morpheme은 새 lexical word를 만드는 데 쓰여 open class와 연결되고, inflection은 functional 성격에 가깝다.

Lexical (open class)
blog, email, download새 동사 to google 처럼 쉽게 추가
Functional (closed class)
the, of, because, them새 preposition·article은 사실상 생기지 않음
📋 개념 확인

lexical vs functional morpheme, open/closed class 구분이 morpheme classification에서 서로 다른 기준이다.

free/bound와 lexical/functional 구분

river는 free·lexical, the는 free·functional이다. 따라서 free이면 lexical이라는 추론은 틀린다. -ed는 bound이고 past라는 grammatical function을 표시한다.

open/closed class는 새 구성원을 받아들이는 정도다. open class라고 해서 모든 lexical word가 새 단어라는 뜻은 아니다. functional word에도 의미나 grammatical function이 있다. 이 절의 lexical/functional 표는 free morpheme을 소개하는 분류이며 bound root가 없다는 뜻은 아니다.

⚖️ ③ Inflection vs Derivation the core contrast ▼
Core Definition
Inflection marks grammatical function only and never changes grammatical category; the traditional teaching inventory lists eight inflectional suffixes; irregular inflected forms also exist. Derivation makes a new word, may change category, and uses prefixes or suffixes.

핵심 판별: 품사가 바뀌거나 새 단어가 생기면 derivation, 같은 단어의 문법형이면 inflection.

inflection은 수·시제·비교·소유 같은 문법 기능만 표시하며 새 단어를 만들지 않는다. derivation은 새 lexical word를 만들고 품사를 바꿀 수 있다.

표를 좌우로 밀어 비교할 수 있어요.

📋 개념 확인

derivational vs inflectional morpheme 구분이 핵심 판별 기준이다.

품사가 같아도 derivation일 수 있다

pack → repack은 V→V지만 새 lexeme을 만드는 derivation이다. pack → packed는 문장 속 past form을 만드는 inflection이다. 품사가 그대로라는 이유만으로 inflection이라고 판단하면 안 된다.

gardeners는 [[garden-er]-s]로 분석한다. 사람을 나타내는 N을 만든 뒤 plural을 표시하므로 -er는 derivation, -s는 inflection이다. colder의 -er는 comparative이므로 같은 소리라도 다른 morpheme이다.

8개 목록은 기능별 suffix 목록이다. brought 같은 irregular past도 inflection이므로 ‘inflection = 눈에 보이는 suffix를 하나 더하기’로 정의하지 않는다. They are painting의 painting은 verbal form이다. -ing 철자만 보고 모든 문맥의 품사를 확정하지 않는다.

기출 대조 · 같은 철자보다 단어 안의 기능 13 26

love(N) → lovely(A) → lovelier(A)에서 -ly는 adjective를 만드는 derivational affix, -er는 comparative를 표시하는 inflectional affix다. lovely의 -ly를 adverb-forming -ly로 읽으면 안 된다. 접사마다 입력 품사·출력 품사·문법 기능을 따로 확인한다.

[[neighbor-hood]-s]에서는 N→N인 -hood도 새 lexeme을 만드는 derivation이고, 바깥 -s는 plural inflection이다. 품사 유지와 의미의 완전한 예측 가능성을 같은 기준으로 보지 않는다. 파생어의 관습적 의미는 별도로 확인한다.

🔧 ④ Affix types — prefix / suffix, class-changing vs class-maintaining 붙는 위치와 품사 변화의 구분 ▼
Core Definition
By position: prefix (before the base) vs suffix (after the base). By effect on word class: class-changing derivational affixes change part of speech; class-maintaining ones keep it.

영어 prefix는 대체로 class-maintaining(un-, re-, dis-)이고, 많은 suffix가 class-changing(-ness, -ize, -ly)이다.

붙는 위치와 품사 변화는 별개의 기준이다: un- 는 prefix이면서 class-maintaining, -able·-ize 는 suffix이면서 class-changing.

※ 이 축(POS 기반)은 Class 1 / Class 2 음운 분류(⑨ 참조)와는 다른 개념이다. "class"라는 단어만 공유한다.

Class-changing (category-changing)
-ness A→N: kind→kindness-ize N/A→V: modern→modernize-ful N→A: care→careful-ly A→Adv: quick→quickly
Class-maintaining
un- A→A: kind→unkindre- V→V: write→rewritedis- V→V: agree→disagree 류 prefix 다수
Class-changing suffix: employ(V) → employment(N); beauty(N) → beautiful(A) Class-maintaining prefix: legal(A) → illegal(A); write(V) → rewrite(V) Position vs effect 독립: un- 는 prefix이면서 class-maintaining; -ize 는 suffix이면서 class-changing.
📋 개념 확인

derivation / affixation 과 단어 형성, 부정 prefix 선택을 예문에서 판별한다.

prefix/suffix와 품사 변화는 별개

rich → enrich: prefix en-, A→V, derivation. child → childhood: suffix -hood, N→N, derivation. prefix이면 품사가 절대 안 바뀌거나 suffix이면 반드시 바뀐다는 규칙은 없다.

dark → darken의 -en은 A→V derivation이고 has eaten의 -en은 past-participle inflection이다. affix의 철자 대신 base의 category, 결과 category, 문장 속 기능을 함께 쓴다.

🔀 ⑤ Allomorphy — conditioned variants of a morpheme phonologically conditioned ▼
Core Definition
An allomorph is one of the variant phonetic forms of the same morpheme (same meaning/function). The variants are typically phonologically conditioned — the surrounding sounds decide which form appears.

한 morpheme이 서로 다른 형태로 실현될 때 그 변이형들이 allomorph다. 같은 의미·기능을 나타내지만 실현되는 형태가 다르다.

📋 개념 확인

allomorph 와 phonological conditioning (plural -s, negative prefix in-/im-/il-/ir-)을 예문에서 판별한다.

plural과 past의 allomorph 선택 순서

regular plural에서는 base가 sibilant /s z ʃ ʒ tʃ dʒ/로 끝나는지 먼저 확인한다: watches의 ending은 [ɪz] 또는 [əz]이다. 그 밖에서 cliffs는 voiceless /f/ 뒤 [s], keys는 voiced vowel 뒤 [z]다. ‘voiceless 뒤 [s]’만 쓰면 voiceless sibilant를 잘못 예측한다.

regular past에서는 base가 /t,d/로 끝나는지 먼저 확인한다: waited는 [ɪd], laughed는 /f/ 뒤 [t], cleaned는 /n/ 뒤 [d]. 철자 gh가 아니라 실제 마지막 소리를 본다.

a university와 an hour도 철자 u/h가 아니라 첫 소리 /j/와 vowel로 판단한다. 또 oxen의 plural은 마지막 소리만으로 예측할 수 없다. 따라서 allomorph가 모두 phonological conditioning으로 결정된다고 설명해서는 안 된다.

in-/im-/il-/ir- 분포는 이 negative-prefix 계열 안에서 설명한다. /m/으로 시작해도 unmarked처럼 un-을 쓰는 단어가 있다. phonological alternation과 어떤 prefix가 그 base에 허용되는지는 별도 문제다.

기출 대조 · 같은 소리로 닮는가, 다르게 되는가? 20

negative prefix in-의 /n/이 base 첫 /l/ 또는 /r/에 동화되어 il-/ir-로 나타난다: assimilation. 반면 solar / rural의 adjectival -ar / -al은 base의 마지막 liquid와 다른 [lateral] 값을 갖는다: dissimilation.

base-final /l/ [+lateral] → -ar /r/ [−lateral]base-final /r/ [−lateral] → -al /l/ [+lateral]

Prefix는 base의 첫 소리, suffix는 마지막 소리를 비교하고, 두 소리의 자질 값이 같아지는지 달라지는지 판정한다. 이 분포는 문항의 자료에 대한 일반화이며, 모든 -al/-ar 단어의 무예외 규칙으로 확대하지 않는다.

🏗️ ⑥ Word-formation processes derivation · compounding · conversion · clipping · blending · acronym · backformation ▼
Core Definition
새 단어를 만드는 과정들. derivational affix로 새 lexeme을 만들면 derivation, 단어를 합치면 compounding, affix 없이 품사만 바꾸면 conversion, 잘라내면 clipping, 두 단어를 합치면서 적어도 한쪽의 일부를 줄이면 blending, 머리글자를 단어처럼 읽으면 acronym, affix를 떼어내면 backformation이다.

conversion / zero-derivation / functional shift와 word-formation process를 예문에서 구별한다.

자세히 보기: 2021학년도 A 2번의 단어 형성 순서

먼저 읽을 기호: N은 noun, V는 verb, A는 adjective라는 품사 표시다. 화살표는 단어를 읽는 순서가 아니라 앞 단계의 결과에 다음 과정이 적용되는 순서다. lexeme은 여러 문법형을 하나로 묶는 어휘 단위로, box·boxes가 명사 BOX의 단수·복수형인 것과 box에서 ‘상자에 넣다’라는 동사 BOX를 만드는 것은 다르다.

2021학년도 전공 A 2번은 box를 noun으로 가정하고 unboxing의 마지막 과정을 inflection으로 제시한다. 따라서 box(N) → box(V)는 conversion, box(V) → unbox(V)는 derivation이다. 출발점은 noun이고 마지막 과정은 inflection이라는 발문 조건을 먼저 고정한다. box(N)에서 box(V)로 갈 때 소리·철자는 같고 품사만 달라지므로 conversion이다. 그 동사에 ‘동작을 되돌림’의 un-을 붙여 unbox(V)를 만들면 뜻이 다른 lexeme이 되므로 derivation이다. V→V라는 이유로 inflection이라 판단하면 틀린다. 따라서 두 빈칸에는 conversion → derivation 순으로 쓴다.

변형 연습: button을 noun에서 시작한다고 가정한 She is unbuttoning the coat에서는 button(N) → button(V) → unbutton(V) → unbuttoning 순으로 분석한다. 먼저 각 화살표에 과정명을 붙여 보자. 첫 단계는 affix 없는 category change이므로 conversion, 둘째는 reversative prefix를 붙이는 derivation, 마지막은 is와 함께 progressive form을 만드는 inflection이다. 시작을 button(V)로 바꾸면 conversion 단계가 사라진다. 단어의 겉모양이 같아도 발문이 지정한 출발 품사를 확인해야 한다.

laboratory → lab는 한 단어를 줄인 clipping, web + seminar → webinar는 web 전체와 seminar의 일부를 합친 blending이다. 두 원단어를 모두 잘라야 하는 것은 아니다. 원서의 info + commercial → infomercial도 info는 유지하고 commercial의 일부를 줄인 예다. backformation은 단순히 길이가 짧아진다는 뜻이 아니라 실제·추정 affix를 제거하여 새 lexeme을 만든 역사적 과정이다. 현재 단어쌍만 보고 생성 방향을 추측하지 않는다.

2011 X26의 xerox는 상표명이 일반 명칭으로 쓰인 coinage의 예다. sub는 substitute를 줄인 clipping이고, typewriter → typewrite는 추정 suffix를 제거한 backformation이다. raincheck는 rain과 check의 compounding, empty(A) → empty(V)는 affix 없는 conversion이다. 현재 철자만이 아니라 제시된 어원·변화 방향을 함께 본다.

기출 연결 · 명사화할 때 무엇이 남아야 할까? 08

nominalization은 category뿐 아니라 참여자와 내용의 표현도 바꾼다. Lea discovered that the birds existed.를 Lea’s discovery of the existence of the birds로 바꾸면 Lea는 발견자, existence of the birds는 발견한 내용이다. discovery of the birds로 줄이면 ‘새들의 존재를 발견했다’는 내용을 그대로 보존하지 못한다.

명사 뒤의 preposition도 일률적으로 of가 아니다. They opposed the plan에 대응하는 명사구는 their opposition to the plan이다. 여러 문장을 압축해도 누가 무엇을 했는지와 어떤 내용을 말했는지를 유지해야 한다.

🔗 ⑦ Compounding — headedness, endocentric vs exocentric rightmost head · compound vs phrase ▼
Core Definition
A compound combines two or more words into a new word. In a typical English endocentric compound, the rightmost element is the head: it determines the category and the kind of entity denoted. This is not a rule for every compound.

endocentric compound는 head의 하위어(a kind of head)다 — armchair = a kind of chair.

exocentric compound (headless)는 어느 요소의 하위어도 아니다 — pickpocket = a person, not a pocket.

category determination: 대표적인 right-headed compound에서는 오른쪽(final) 요소가 전체 품사를 결정한다. exocentric의 의미를 이 규칙만으로 예측하지 않는다.

작은 화면에서는 그림을 좌우로 밀어 볼 수 있어요.

Endocentric (head의 하위어)
teapot = a kind of potraincoat = a kind of coatblackbird = a kind of bird
Exocentric (어느 쪽도 아님)
scarecrow = a device, not a crowturncoat = a traitor, not a coathighbrow = a person
Head 결정: overflow (preposition+verb → verb), handmade (N+A → A) Compound vs phrase (강세): bláckboard 'chalkboard' (compound, 첫 요소 강세) vs black bóard 'a board that is black' (phrase, 둘째 강세) Inflection 위치: toothbrushes (전체에 부착) teethbrush (toothbrush의 복수형으로 불가) 이 예의 복수 표지는 toothbrush 전체에 붙는다. 모든 compound가 첫 요소의 복수를 금지한다는 뜻은 아니다. overflow의 head는 rightmost flow이지 over가 아니다.
📋 개념 확인

compounding을 다른 word-formation process와 구별하고, 예문에서 head를 찾는다.

compound의 head와 의미 확인

snowball은 ball의 한 종류이므로 endocentric이고 오른쪽 N이 category와 의미 범주를 정한다. pickpocket은 N이지만 pocket의 한 종류가 아니므로 exocentric이다. 오른쪽 요소와 전체의 품사가 같더라도, 전체가 그 요소의 한 종류를 뜻하는지는 따로 확인해야 한다.

기존 blackboard / black board 대조에서 compound는 관습적 명칭이고 phrase는 색을 기술한다. 강세는 유용한 단서지만, 강세 하나만으로 모든 compound와 phrase를 구별할 수는 없다. 띄어쓰기·hyphen도 단독 판별 기준이 아니다.

toothbrushes의 -es는 전체 compound의 plural이다. 이를 ‘compound 내부에는 plural이 절대 없다’로 확대하지 않는다. sports car처럼 첫 요소에 -s가 있는 관습적 compound도 있다.

🌳 ⑧ Hierarchical word structure — tree / bracketing & ambiguity [un-[V-able]] vs [[un-V]-able] ▼
Core Definition
Morphologically complex words are built in ordered steps, giving hierarchical (layered) internal structure shown by a tree or bracketing. Each affix's input/output category restricts the order.

Ambiguity from structure: un- 는 두 개의 distinct morpheme이다 — (a) un- + Adjective → Adjective ('not', unhappy); (b) un- + Verb → Verb ('reverse of', untie).

두 중간 형태(V-able과 un-V)가 모두 허용되면 un + V + able은 두 구조에 따른 ambiguity를 가질 수 있다. bracketing이 의미를 가른다는 점이 핵심이다.

Bracketing ambiguity: unbuttonable

Bracketing ambiguity: unbuttonable = [un-[button-able]] 'not able to be buttoned' vs [[un-button]-able] 'able to be unbuttoned' Ordering fixed: unwearable = [un-[wear-able]] only (-able 가 동사 wear에 먼저 붙어야 함; 그 뒤 adjectival un- 이 형용사 wearable에 부착) re-[washable] — washable은 adjective라 이 예의 V-selecting re- 부착 불가 각 affix의 input/output 품사 제약(selectional restriction)이 derivation 순서를 결정한다.
📋 개념 확인

hierarchical structure / bracketing ambiguity (un-…-able 류)를 예문에서 판별한다.

두 해석에 맞는 구조가 모두 가능한가?

기존 unbuttonable의 왼쪽 tree는 먼저 buttonable(A)를 만들어 ‘채울 수 있는’을 얻고, un-이 이를 부정한다. 오른쪽 tree는 먼저 unbutton(V)을 만들어 ‘풀다’를 얻고, -able이 그 동작의 가능성을 나타낸다. 최종 품사는 둘 다 A지만 un-이 붙는 대상과 의미가 다르다.

unwearable은 표준 의미에서 wearable(A)에 negative un-이 붙는다. ‘입는 행위를 되돌리다’라는 일반적인 unwear(V)를 먼저 가정하여 두 번째 해석이 있다고 판단하면 안 된다. un…able이라는 겉모양만으로 ambiguity가 있다고 판단하지 않는다.

rewashable의 반복 의미 re-는 wash(V)를 입력으로 선택한다. wash → rewash → rewashable의 각 단계의 품사를 V, V, A로 표시하면 [re-[washable]]이 왜 이 분석에 맞지 않는지 드러난다. morpheme을 나눈 뒤, 각 단계에서 만들어지는 base의 품사와 의미를 확인한다.

📈 ⑨ Productivity, lexicalization & derivational constraints 생산성 · 제약 ▼
Core Definition
Productivity is the degree to which a process applies freely to new bases. Inflection and some affixes (-ness, -ly) are highly productive; others are restricted by phonological/category constraints.

derivational constraints: 일부 affix는 base의 형태를 선택한다. -en(causative, A→V)은 대표적인 생산적 A→V 패턴에서 monosyllabic + obstruent-final이라는 phonological 조건을 갖는다. 이 조건만으로 모든 결합이 보장되지는 않는다. N-forming -al(V→N)의 final-stress 조건도 필요조건으로 다룬다.

lexicalization: 표현이 관습적인 어휘 항목으로 굳는 현상. 그 의미가 구성 요소의 뜻만으로 예측되지 않을 수 있다 (business < busy+ness, 하지만 'state of being busy'가 아님).

Productive / 적용
bright → brightenshort → shorten(monosyllabic + obstruent-final 만족)
Phonological restriction / 제약
calmen (/m/ sonorant 종결)curiousen (polysyllabic)
Level-ordering note (개념 소개 수준)

Class 1 affix는 강세 이동·분절 변화를 일으킬 수 있고(-ity, -ion), Class 2 affix는 음운적으로 중립적이다(-ness, -less). Class 1이 보통 root에 더 가깝게 위치한다.

※ 이 Class 1 / Class 2 (음운 분류)는 ④의 class-changing / class-maintaining (POS 분류)과 다른 축이다. 혼동 금지.

bright → brighten, short → shorten (허용되는 파생형) calmen (ends in /m/, sonorant) · curiousen (polysyllabic) understand ≠ 'stand under' — lexicalized productivity는 한 과정이 새 base에 얼마나 자유롭게 적용되는가의 정도다.
📋 개념 확인

derivational productivity·constraint 및 lexicalization은 형태론 심화 개념으로 다룬다.

발음 조건만으로 파생형을 만들 수는 없다

dark → darken은 monosyllabic·obstruent-final base의 표준 예다. calm은 마지막 /m/이 sonorant여서 이 -en 패턴에 맞지 않고, curious는 polysyllabic이다. 두 실패를 같은 이유로 처리하지 않는다.

발음 조건에 맞더라도 해당 affix가 그 품사와 의미의 base에 실제로 붙는지 확인해야 한다. 필요조건은 맞지 않는 예를 걸러 주지만, 조건에 맞는 모든 결합이 실제 단어로 쓰인다는 뜻은 아니다.

N-forming -al의 final-stress 조건은 arrive → arrival과 refuse → refusal 같은 패턴을 설명한다. 하지만 final stress만으로 모든 verb가 -al을 허용하지 않는다. 또 musical의 A-forming -al과 input/output category가 다르므로 하나의 규칙으로 합치지 않는다.

lexicalization은 관습화된 의미를 개별 학습해야 하는 경우와 연결된다. 낮은 productivity, phonological 조건 위반, 기존 단어에 의한 blocking은 서로 구분해서 설명한다.

기출 적용 · -al의 입력 조건과 결과 강세 구분 14 23

Noun-forming -al suffix는 V→N이다. reFUSE → reFUsal에서 base의 마지막 음절에 있던 primary stress는 suffix가 붙은 noun에서는 끝에서 둘째 음절에 놓인다: penultimate stress. 마지막 strong–weak 두 음절은 trochaic foot를 이룬다. 입력 verb의 ultimate stress와 출력 noun의 penultimate stress는 서로 다른 단어를 기준으로 한 설명이다.

2014 A05는 자음 조건도 요구한다. arrive의 /v/와 acquit의 /t/는 [+anterior]지만 rebuke의 /k/는 [−anterior]다. rent의 /nt/와 accept의 /pt/는 끝 /t/가 같으므로 그 앞 자음을 비교한다: /n/은 [+sonorant], /p/는 [−sonorant]다. 두 자음이면 첫째가 [+sonorant], 둘째가 [+anterior]인지 확인하고 지문의 stress 조건도 함께 적용한다. 이 필요조건만으로 모든 결합이 실제 단어가 된다고 판단하지 않는다.
